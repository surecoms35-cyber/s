# ТРЦ «МЕГА-ХАПУГА»

Стелс-игра на Unity от первого лица: пробираешься в торговый центр, тыришь всё, что плохо лежит,
и сваливаешь через главный вход, пока охрана тебя не скрутила, а ТРЦ не закрылся.

## Как запустить

Нужен Unity **2021.3 или новее**, Built-in или URP.

**Вариант 1:** Unity Hub → *Add project from disk* → выбрать эту папку → открыть → нажать **Play**.
Сцена не нужна — весь ТРЦ строится кодом при старте любой сцены (даже пустой `Untitled`).

**Вариант 2:** создать новый 3D-проект и скопировать туда папку `Assets/MallHeist` → **Play**.

Работает и со старым Input Manager, и с новым Input System.

## Управление

| Клавиша | Действие |
|---|---|
| WASD + мышь | ходить / смотреть |
| Shift | бежать (с набитым рюкзаком — палевно) |
| C / Ctrl | красться (охрана видит тебя хуже) |
| E | спиздить товар, на который смотришь |
| G | выкинуть последнюю вещь из рюкзака |
| Esc / клик | отпустить / захватить мышь |
| R | заново (на экране итогов) |

## Механики

- **8 магазинов**: «Пятёрка», «Зарина», «М.Видос», «Золотой Лось», «Сделай Сам», «Детский Мирок»,
  «Золотое Яблочко», «Спортмастерище». Чем дороже магазин, тем лучше охраняется.
- **Охрана** (4 человека) патрулирует ТРЦ с фонариками. Синий — спокоен, жёлтый — ищет, красный — гонится.
  Палит, если видит, как ты что-то берёшь или бежишь с хабаром. Во время тревоги хватает при первом же взгляде.
- **Камеры** в дорогих магазинах крутятся туда-сюда. Засекли кражу — тревога, ближайшие охранники бегут на место.
- **Примерочные** в «Зарине» и «Спортмастерище» — залезь внутрь, и тебя не видно.
  Но если охранник видел, как ты туда нырнул, — придёт и достанет.
- **Рюкзак** держит 30 кг; чем тяжелее, тем медленнее бежишь. Телевизор за 90 косарей — 18 кг. Думай.
- **Время**: 5 минут до закрытия. Цель — вынести на 500 000 руб.

## Структура

```
Assets/MallHeist/Scripts/
  MallBootstrap.cs    — генерирует ТРЦ, магазины, товары, охрану, камеры
  GameManager.cs      — состояние игры, тревога, таймер, HUD, сирена
  PlayerController.cs — игрок от первого лица, рюкзак, кража
  Guard.cs            — ИИ охранника (патруль / проверка / погоня / поиск)
  SecurityCam.cs      — камеры видеонаблюдения
  NavGrid.cs          — сетка проходимости + A* (без NavMesh)
  Vision.cs           — конус зрения с проверкой прямой видимости
  HidingSpot.cs, Loot.cs, Prim.cs, GameInput.cs
```

*Игра — шутка. В реальной жизни не пиздите, там охрана не тупит в стеллажи.*
